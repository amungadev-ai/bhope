# Beacon of Hope 0.3

## Layout and navigation

Five tabs are now Today | Bible | Notebook | Inspiration | More. The More tab contains its own drawer and fixed header. The Home header has an optional shortcut to that drawer. Other screens use their own compact header or a back action, with no repeated hamburger buttons.

Home and Notebook use React Navigation headers outside their scrolling content. The Bible keeps book/chapter controls, Bible-only EN/SW, search, and version information in a fixed toolbar. Its ellipsis opens verse actions when a verse is selected; the version badge opens reading-size/version information.

The note editor prioritizes writing. Its fixed top row has back/save, a single-line title, and a three-dot menu. Formatting, sermon/reflection type, preacher/church/date, reference list, export, and delete live in that menu. Bible and reflection shortcuts stay in a slim footer. The editor uses the available height with KeyboardAvoidingView; it no longer requires discovering a horizontally scrolling formatting bar.

A normal reference tap shows a compact passage preview. The bottom-right ellipsis expands save, copy, share, open Bible, and insert actions. A long press can open the options directly.

## Language and themes

App language is controlled only under More → Preferences. The Bible EN/SW switch changes the Bible text and book names without changing app menus or devotionals. Both preferences survive restarts. Existing language preferences seed the independent Bible language once.

Preferences offers the original Evergreen palette plus Ocean, Plum, and Warm Sand. The selected theme applies to navigation, reading, notes, sheets, and the local rich editor, and remains selected after restart.

## AI

Five free uses once per reader account, then a KES 150/month plan. The backend enforces lifetime allowance and access expiry. Failed provider responses restore trial credit; a separate daily request limit applies. The app and admin studio show matching plan/access information. Real checkout is not configured; see [AI access and billing](AI_ACCESS.md).

## Update from Windows

Stop Expo with Ctrl+C. In PowerShell:

```powershell
Set-Location "$HOME\Projects\bhope"
git pull origin main
npm ci
Set-Location .\apps\mobile
npx expo start --clear
```

The existing SQLite notebook database is preserved. Export important notes before clearing app data or reinstalling Expo Go. Old rich notes with empty plain-text copies rebuild that text when opened, so search, export, word counts, and AI use the visible words.

Run `npm run db:migrate` when updating the API to add the new AI tables. No merchant key, database password, full licensed Bible text, or local test data is included in the update.

Physical Android keyboard positioning, selection/long presses, and system back behavior still need on-phone review. Browser checks at compact viewport sizes validate layout but do not replace Android keyboard tests. Live subscriptions need store configuration and a development build; core app review continues in Expo Go.
