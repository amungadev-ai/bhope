# Beacon of Hope 0.4

This revision restores a more relaxed reading and writing layout while keeping the five tabs, independent languages, saved themes, and existing note data.

## Bible

The fixed header has room for the title/version, Bible language, and a text-size action. A clear second row selects book, chapter, and verse range; search stays below. There is no three-dot header menu.

Choose “All verses” to enter start/end verses. The picker checks valid endpoints in the current chapter/translation and rejects descending ranges. An explicit range filters the reader; “Read the whole chapter” restores context. Search ranges also select a reading range. A long press within a selected range opens actions for that range; with no range selected it acts on the individual verse.

Verse rows use less padding, smaller gaps, and tighter line height. A long press opens a concise sheet with save, copy, share, and add-to-note actions immediately available. The Bible sheet has a short preview and omits repeated version labels. The note's passage sheet keeps the full passage with direct Open in Bible/Insert actions. Neither sheet has an action ellipsis.

## Notebook

The editor has a prominent title again, with a small sermon/reflection details row. Bold, italic, underline, heading, bullet list, and checkboxes are visible in the editor toolbar. A chevron expands paragraph, numbered-list, undo, and redo tools into a second row; no horizontal scrolling or formatting sheet is required.

The bottom/footer bar and its Bible connection have been removed. Bible navigation remains available through each detected blue reference's passage sheet. Detected references appear only as blue inline links. Reflection assistance remains a small header action, retaining the existing account/consent/allowance checks.

Long press a note in the notebook list to rename, share, or delete. Rename preserves the latest rich content and sermon metadata. Delete asks for confirmation; cancelling keeps the note.

## More

More is a personal reading corner with an original reflection prompt, actual local notebook and saved-verse counts, the most recent note, and a saved verse. Empty libraries get an invitation to read/write. Account, preferences, AI access, giving/history, TikTok, and About remain available from the drawer rather than a duplicate menu list.
