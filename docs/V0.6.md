# 0.6: devotional reader, archive, and complete Bible testing

## Reader

Back, title, subtitle, and reading minutes stay in a fixed header. Top and bottom safe-area insets protect the phone status/navigation regions; the scroll content has an additional 32 px bottom cushion. The passage can open the Bible and return to the same devotional. Reflection notes and daily completion keep the existing storage formats.

## Past devotionals

The Home card after Keep growing opens the devotional library. Readers can search either language title, set inclusive publication-date ranges, and switch newest/oldest order. Date fields use YYYY-MM-DD, with All time and Last 30 days presets. Dates use Nairobi time consistently on the API and device.

`GET /api/v1/devotionals/archive` returns `items`, `total`, `page`, `limit`, and `hasMore`. Query parameters are `q`, `from`, `to`, `order`, `page`, and `limit` (maximum 40). The latest-feed endpoint stays backwards compatible. `GET /api/v1/devotionals/:id` opens a published reading even when it is outside the latest 60 entries. Neither endpoint exposes drafts, reviews, unscheduled content, or future publication dates. No schema migration is required.

The library can use saved readings offline. Opening older readings does not change the newest Home reading. Bundled reflections without an editorial publication date are labelled Saved reflection and are excluded from date filters. New historical content and dates come from the existing editor/admin publishing workflow.

## Complete Bibles on Windows

The supplied NIV and Swahili XMLs validate to 31,102 verses, 1,189 chapters, and 66 books each. The private testing pack contains the generated `.local/bible.json`, with both complete translations and their original metadata. It stays separate from the public repository.

Download `bhope-full-bibles.zip` into Downloads, stop Expo, and run from the project root:

```powershell
git pull origin main
Expand-Archive -Path "$HOME\Downloads\bhope-full-bibles.zip" -DestinationPath . -Force
Set-Location .\apps\mobile
npx expo start --clear
```

Alternatively use the existing `npm run bible:import` command with your local XML paths. The mobile resolver automatically chooses the local complete library. The SQLite fingerprint import changes the Bible verse table and preserves existing notes, preferences, and bookmarks. First preparation may take a moment. No package installation is needed for this update.

## Access

Daily devotionals, their archive, the Bible, and notebook remain free. Giving and the planned AI subscription remain separate; this update adds no donor rewards, purchases, or recurring charges. Paid articles/modules remain future work.

## 0.6.2 Metro Bible loader

The existing private pack remains at `.local/bible.json`. Before Metro starts its file map, a small loader prepares an identical regular file at `apps/mobile/assets/private-bible/bible.json`. The generated asset folder is excluded from Git. Identical contents retain the prepared file's timestamp; a replaced pack updates the copy atomically. The original pack is preserved.

The Bible alias delegates to normal Metro resolution inside the mobile project. The earlier custom watch-folder and block-list additions are removed, leaving Expo's defaults intact. Missing packs and explicit sample mode keep the sample fallback.

Stop existing Expo sessions, pull the update, and start a fresh Expo server with `npx expo start --clear`. Scan its new QR code. The Bible pack does not need to be downloaded or extracted again.
